# Audit Gauntlet

Private administrative index for Richard's Audit Gauntlet investigations.

[Open the publication index](PUBLISHING_INDEX.md) for each programme's canonical local path, GitHub repository, published commit, scientific status, latest report and upload exclusions.

Investigation source and histories live in their own repositories. The-Boundary-Doctrine remains separate. Scientific analyses and gates are governed by the programme records; publishing does not resume an investigation.

The `publication/` directory contains the publication inventories, admitted-file hashes, history checks, remote verification and records of local files intentionally omitted from GitHub. No observational archives are held in this repository.
